# License decision required

No license has been added because the correct choice depends on the authors'
institutional, funder, coauthor, and data-use requirements.  Without a license,
others generally do not receive permission to reuse the code.

Before publishing, choose a license with all copyright holders' agreement and
add its unmodified text as `LICENSE`.  Common choices for research software
include MIT, BSD-3-Clause, and Apache-2.0; consult the institution's guidance
if patent, attribution, or copyleft terms matter.  Remove this note once the
repository has its selected license.
