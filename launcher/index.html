Diffeomorphic Monte Carlo

Set up once, choose an experiment, and run it with a click.

Open Start.bat (Windows), Start.command (macOS), or run START_HERE.py in IDLE.

This HTML file is the launcher’s interface. Opening it directly does not start the experiment runner.

1. Set up

Checking environment…

The setup button creates a separate Python environment and installs the required packages. Internet access is needed for this step.

Install Python 3.12 if needed ↗

Use the 64-bit installer. On Windows, select “Add python.exe to PATH”. After installing, click Set up again.

2. Run experiments

The default comparison runs synchronized groups of chains, one method at a time. Other experiments assign the next waiting chain when a worker finishes. More workers use more RAM; keep the same setting across methods. Fitting, plotting and four-chain logistic reference preparation may use fewer cores.

Vanilla skips map fitting and keeps the experiment’s β. Both choices use the same proposal-scale warmup and freeze it before sampling. SCS and the identity maps in Eight Schools and GARCH are unchanged. Results record the choice.

All experiments discard the first third of generated sampling iterations after separate tuning. Keep this launcher open and prevent the computer from sleeping during a run. Completed chains are saved automatically.
